📖 使用说明

自动查询条件：
当 URL 包含完整的查询参数时，页面会自动执行查询并滚动到结果区域。

URL 参数格式：
protocol - 协议类型（TCP/UDP/ICMP）
sourceIp - 源 IP 地址
sourcePort - 源端口
targetIp - 目标 IP 地址
targetPort - 目标端口

分享功能：
查询完成后，点击 "查询咨询" 按钮可以复制当前查询的 URL 链接，方便分享给其他人。
